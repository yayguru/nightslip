Nightslip

Prove “I earn at least X” in zero knowledge, without showing the salary, the employer, or the payslip.
Compact contract · midnight-js 4.1.1 · Apache-2.0

The problem

To rent a flat, get a loan or a work visa, people send full payslips and bank statements to strangers.

The verifier needs one bit: income ≥ threshold? They receive salary, employer, tax ID, address.

1 bit

is all a landlord needs. Today they get the whole document, and keep it.

How Nightslip works

1 · AdminPayroll provider / registry registers employer keys on chain.
2 · EmployerIssues a payslip. Only a hiding commitment enters a HistoricMerkleTree.
3 · EmployeeProves amount ≥ threshold and period ≥ minPeriod for the verifier's challenge, using a ZK proof.
4 · VerifierReads attestations[challenge] = {threshold, minPeriod}. Nothing else.

Private: amount · employer · employee · which slip.  Public: commitment, nullifier, the verifier's own threshold.

Contract (Compact)

export circuit proveIncome(threshold: Uint<64>,
    minPeriod: Uint<32>, challenge: Bytes<32>): [] {
  const sk = secretKey();
  const s  = heldSlip();
  const c  = slipCommitment(publicKey(sk), s);
  const path = slipPath(c);
  assert(slips.checkRoot(disclose(
    merkleTreePathRoot<16, Bytes<32>>(path))), ...);
  assert(s.amount >= threshold, ...);
  assert(s.period >= minPeriod, ...);
  const n = nullifier(sk, c, challenge);
  assert(!nullifiers.member(disclose(n)), ...);
  nullifiers.insert(disclose(n));
  attestations.insert(disclose(challenge), ...);
}
  • Commitment binds issuer, employee key, amount, period, salt
  • Only registered issuers can add slips, in their own name
  • Stolen slip is useless without the holder's key
  • Nullifier + challenge: no replay
  • Domain-separated persistentHash

Who pays for this

  • Payroll / EOR platforms: “proof of income” API as a feature
  • Rental platforms: income ≥ 3× rent check without document storage (GDPR win)
  • Lenders / BNPL: pre-qualification without data collection
  • Consulates: digital-nomad visa income floors

Model: issuers pay per issued slip; verifiers pay per verification. Holders free.

Why Midnight: private state plus selective disclosure is native, not bolted on.
